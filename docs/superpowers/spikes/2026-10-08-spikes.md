# Spikes — 2026-10-08

## Spike 1 — tải EPUB của repo private từ trình duyệt (CORS)

Repo thử: `PNThanggg/hako2epub-spike` (private). Mô phỏng đúng chuỗi request của
`fetch()` từ origin `https://pnthanggg.github.io` bằng script Python (không tự
theo redirect; khi theo redirect thì bỏ `Authorization` và dùng `Origin: null`
như trình duyệt làm với redirect khác origin).

| Phương án | Kết quả |
|---|---|
| Preflight `OPTIONS api.github.com/.../releases/assets/{id}` | 204, `Access-Control-Allow-Origin: *`, cho phép header `Authorization` |
| `GET .../releases/assets/{id}` + `Accept: application/octet-stream` | 302 → `release-assets.githubusercontent.com/...` (`ACAO: *` ở bước 302) |
| `GET` URL đã ký ở `release-assets.githubusercontent.com` | 200 nhưng **không có** `Access-Control-Allow-Origin` (cả `Origin: null` lẫn origin thật) → trình duyệt chặn |
| `PUT /contents/<path>` lên nhánh `files` (file 5 MB ngẫu nhiên) | 201 |
| `GET /contents/<path>?ref=files` + `Accept: application/vnd.github.raw` | 200, `Access-Control-Allow-Origin: *`, 5 242 880 byte, trùng khớp từng byte, không redirect |

Kết quả: FAIL với Releases, PASS với files-branch
Quyết định: files-branch
Task 4/5/17 dùng biến thể files-branch.

Ghi chú:
- Contents API giới hạn 100 MB mỗi file khi đọc dạng raw; body PUT là base64
  (+33%). EPUB lớn hơn khoảng 70 MB cần đẩy bằng git thay vì Contents API (ngoài
  phạm vi bản đầu; worker báo lỗi rõ ràng nếu vượt).
- Mỗi lần cập nhật EPUB tạo một blob mới trên nhánh `files`, nên repo phình dần.
  Chấp nhận được cho dùng cá nhân; có thể squash nhánh `files` về sau.
- Đây là mô phỏng bằng script. Lần kiểm tra thủ công ở Task 17 (tải EPUB trên
  điện thoại) sẽ xác nhận lại trên trình duyệt thật.
